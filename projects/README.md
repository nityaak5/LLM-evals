# Projects

Larger, self-contained pieces of work that combine several concepts from
[../exercises/](../exercises/) — e.g. a full eval harness, a judge
calibration study, a benchmark you built end to end.

Each project gets its own subfolder with its own README (what it does, why,
how to run it). Projects are the usual source material for
[../articles/](../articles/).

Projects are usually `.py`, not notebooks — this is where an exercise's
throwaway code turns into something structured enough to import, test, and
run repeatably. The exception is a project that accompanies an article: it
can be a notebook (`.ipynb`), so readers can run it top to bottom and see
the results inline.
